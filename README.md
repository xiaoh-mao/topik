# TOPIK 做题

桌面刷题工具，题目来自 TOPIK 官网「학습 자료실」公开的기출문제：
第 37、41、47、52、60、64、83、91、96、102 回，每回 TOPIK I / II 各一套，共 20 套。
卷子是原版页面，听力是原版录音，正确答案和配分来自官方正答表。
姊妹项目：[JLPT 做题](https://github.com/xiaoh-mao/jlpt)（界面和用法一样）。

## 下载

- 只支持 **Windows 10 / 11**，用系统自带的 Edge 和 PowerShell，不用装别的。
- GitHub 页面上点 **Code → Download ZIP**。解压**之前**先右键 zip → 属性 → 勾「解除锁定」→ 确定，
  不然每次启动 Windows 都会弹安全警告。也可以 `git clone`。卷子页面图和录音都在仓库里，约 1.4 GB。

## 怎么用

1. 双击 **`TOPIK做题.bat`**，会弹出一个独立窗口（Edge 应用模式）。
   想要带图标的桌面快捷方式，就在这个文件夹里运行
   `powershell -ExecutionPolicy Bypass -File scratch\make-ico.ps1 -Shortcut`。
2. 在首页右上角选 TOPIK I / II，选一回，点「整套模考」，
   或者点某一科做分项练习。
3. 窗口关了进度也还在：没交卷的那场回首页点「继续」就能接着做，
   剩余时间和录音播到哪里都会保存。

换电脑时把 `data\` 文件夹拷过去，做题记录和错题本就都带走了。

## 界面分区

**首页**
- 左边：这一级的满分、各等级的分数线、模考时间；下面每回一行：
  듣기 / 쓰기（只有 II）/ 읽기 分项练习（带上次整科做完的成绩）、
  模考最好成绩、「整套模考」。
- 右边：错题本（有多少道待重做）、最近记录。

**做题页**（左卷右卡）
- 左边是**卷子**：顶部标签切换 문제지（II 分 1교시 / 2교시 两本）/ 듣기 대본 / 정답
  （듣기 대본在练习时对过听力答案后出现，订正时都有）。
- 右边是**答题卡**：按卷面上的 [1~4] 这种大题分组，写着中文题型；每题后面的小数字是配分。
  点圈作答，⚑ 标记待检查的题。订正时可勾「只看错题」。
- **쓰기**（TOPIK II 51–54 题）：51、52 每题两个空（㉠㉡）各写一句；53、54 写一段，
  边写边数字数（空格也算，照原稿纸一格一字），不在要求范围里就变红。
- 听力的播放条在答题卡顶上：一个下拉框选大题（开头是「开场说明」），暂停、拖动、±5 秒、变速，
  一段放完自动接下一段。模考和练习都一样。

**成绩页**：总分（I 满分 200，II 满分 300）和等级、各科得分、每个大题的正确率；
쓰기要对照正答表里的模范答案给自己打分，打完才出总分。
可以「对照卷子订正」「再做一遍」「去错题本」。

**错题本**：每道题按最后一次的结果收录，
可以一次重做一回卷子里的全部错题，懂了的手动「移出」。

## 主要功能

- **点题号跳转**：点答题卡上的题号，卷子自动滚到那一题；
  听力题的**录音也会跳到那一题开头**，点大题号就跳到那个大题。
  录音播到哪题，答题卡上就标 ♪；勾选「卷子跟着走」，卷子也会跟着录音翻过去。
  （老卷子扫描得糊，少数题在卷上的位置是估的，题号上悬停会提示。）
- **听力原文 + 中文译文**：「듣기 대본」标签页里每段录音讲完的地方插一张中文译文卡，
  对话、题干和选项（图片选项除外）都有，标签栏右侧「译文」开关可以隐藏。
  译文是 Claude 照原文翻的，不是官方版本。练习时对过这一大题的答案才显示，
  订正时随时能看，模考时不显示。
- **模考**：按真实考试的科目顺序和时限计时（I：읽기 60 分钟；II：쓰기 50、읽기 70，
  읽기前真考试要休息 30 分钟），时间到自动交卷；
  듣기那一节不限时，录音可以随便暂停、回放，做完自己交。
  选择题按官方配分算，TOPIK 本来就按总分定等级（没有单科及格线），所以分数和等级是准的。
- **分项练习**：只做某一科，每个大题做完可以单独「对答案」。
- **订正**：交卷后回到卷子，对错、正答表（含쓰기模范答案）、听力原文都能对照着看。
- **快捷键**：`1`–`4` 作答并跳下一题，`↑` `↓` 换题，`F` 标记，
  `0` 清除；听力时 `空格` 播放/暂停，`←` `→` 快退/快进 5 秒。
- 第 37 回官网只给了一整段录音（别的回都按题拆好了），每题从第几秒开始是按录音里的静音算的，用起来一样。

## 目录

| 路径 | 内容 |
|---|---|
| `TOPIK做题.bat` | 启动入口 |
| `app/` | 界面（纯前端，零依赖）；`core.*` 和 JLPT 做题共用，`exam.*` 是 TOPIK 自己的 |
| `lib/` | 本地小服务（PowerShell）和启动脚本；`exam.ps1` 是 TOPIK 自己的 |
| `papers/` | 官方卷的页面图和录音，每回一个文件夹，里面分 `I` / `II`。原版 PDF 做题用不上，不在仓库里 |
| `data/` | 做题记录和没交卷的进度（第一次运行时自动建） |
| `scratch/` | 生成题目数据的脚本（下载、整理、抄答案、定位、译文），用法写在各文件开头；做题用不上，要什么工具见 `CLAUDE.md` |
